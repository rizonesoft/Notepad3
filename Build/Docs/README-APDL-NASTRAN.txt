Notepad3 - APDL / NASTRAN Windows x64

中文使用说明
1. 完整解压 Notepad3-APDL-NASTRAN-<版本>-x64.zip，再运行其中的 Notepad3.exe。
2. 保持 lng 文件夹与 EXE 同目录。单独复制 EXE 不包含中文语言包。
3. 更新现有程序时可保留自己的 Notepad3.ini；同时更新整个 lng 文件夹。
4. 打开 BDF/NAS 后，在“查看 > NASTRAN 列标尺”选择关闭、8 字符或 16 字符字段。
   第 72 列边界为蓝色，第 80 列边界为橙色；Ctrl+Alt+L 显示/隐藏标尺。
   切换其他语法方案时恢复普通长行标记。自由格式可关闭标尺。
5. 准确检查固定列时，请使用等宽字体、Tab 宽度 8，并关闭自动换行。
   非等宽字体或样式字符宽度不一致时，标尺自动停用；换回等宽字体后恢复原预设。
   标尺只辅助显示，不会修改或自动对齐文件内容。

English
Extract the entire portable ZIP before running its Notepad3.exe. Keep the lng
folder beside the executable; the loose EXE alone has no translated UI resources.
When updating, retain your existing Notepad3.ini if desired and update lng too.

View > NASTRAN Column Guides: Off / 8-character fields / 16-character fields.
Blue marks the boundary after column 72; orange marks column 80. Ctrl+Alt+L toggles
the preset in NASTRAN. Other schemes restore their ordinary long-line markers.
Use a monospace font, tab width 8, and no visual word wrap to inspect fixed cards.
Guides are disabled for proportional or incompatible style fonts and return when
the fonts are compatible again. Guides affect display only. No ANSYS or NASTRAN solver installation is required.
