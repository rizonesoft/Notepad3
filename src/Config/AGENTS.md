# Configuration persistence guidance

Read [Configuration and INI](../../agent-trail/domain/configuration-and-ini.md) before changing settings load/save, redirection, or MRU persistence. Its evidence scope is limited; verify the claim relevant to the change.

For user-visible setting syntax/defaults, consult [Configuration reference](../../readme/config/Configuration.md) and `Build\Notepad3.ini`; do not duplicate that catalog here.

`README.md` in this directory belongs to the bundled SimpleIni library. Its CMake examples are not Notepad3 application build instructions. Use the [Windows build/test guide](../../agent-trail/build-and-test/windows-build-and-test.md) instead.
